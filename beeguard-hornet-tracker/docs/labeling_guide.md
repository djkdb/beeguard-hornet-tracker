# 라벨링 가이드

박스를 일관되게 치는 것이 사진 장 수보다 성능에 더 큰 영향을 줍니다. 이 기준을 라벨링 전에 정하고, 끝까지 같은 기준으로 칩니다.

## 1. 부류 정의

| 부류 (라벨 이름) | 한국어 이름 | 구별 포인트 |
| --- | --- | --- |
| `honeybee` | 꿀벌 (양봉꿀벌) | 몸길이 약 1.2cm, 갈색·주황 줄무늬, 가슴에 털이 많음 |
| `giant_hornet` | 장수말벌 | 몸길이 약 4cm 안팎으로 가장 큼, 크고 주황·노란 머리, 배에 노랑과 검은 갈색 줄무늬 |
| `yellow_legged_hornet` | 등검은말벌 | 몸 대부분이 검고 배 끝 쪽에 주황 띠, 다리 끝이 노란색 |

라벨 이름은 위 표와 글자 하나까지 같아야 합니다. Roboflow는 부류를 알파벳순으로 정렬하므로 `giant_hornet`(0), `honeybee`(1), `yellow_legged_hornet`(2) 순서가 됩니다.

## 2. 박스 치는 규칙

1. **머리부터 배 끝까지** 몸통에 딱 맞게 칩니다. 접힌 날개는 포함하고, 비행 중에 펼친 날개나 길게 뻗은 다리 끝까지 박스를 늘리지 않습니다.
2. **보이는 대상은 전부** 칩니다. 사진 속 꿀벌 20마리 중 5마리만 치면, 나머지 15마리를 "배경"으로 학습해서 성능이 떨어집니다. 너무 많아서 다 칠 수 없으면 그 사진은 뺍니다.
3. **일부가 가려져도 종을 알아볼 수 있으면** 보이는 부분만 칩니다. 종을 알아볼 수 없을 만큼 가려지거나 흐리면, 박스를 생략하지 말고 사진을 뺍니다.
4. **종이 헷갈리면 사진을 뺍니다.** 특히 유럽말벌, 좀말벌, 털보말벌처럼 생김새가 비슷한 다른 말벌 종은 넣지 않습니다.

## 3. 박스 없이 넣는 사진 (Null)

- `hard_negative` 폴더: 꽃등에, 쌍살벌, 호박벌, 집파리처럼 헷갈리기 쉬운 곤충. 모델이 이것들을 말벌·꿀벌로 잘못 잡지 않도록 가르칩니다.
- `background` 폴더: 곤충이 없는 벌통·꽃밭·양봉장 사진.
- Roboflow에서 업로드한 뒤 **Mark Null**로 표시합니다. 이 사진들에 꿀벌이나 말벌이 하나라도 보이면 Null로 두지 말고 박스를 치거나 뺍니다.

## 4. 빼야 하는 사진

- 일러스트, 3D 렌더링, 만화
- 핀으로 고정한 표본, 술병에 담근 말벌(말벌주)
- 글자나 그래픽이 크게 덮인 뉴스 이미지, 워터마크가 대상 위에 있는 사진
- "hornet"으로 검색돼 섞인 전투기(F/A-18 Hornet) 사진
- **추적 영상에 쓸 영상에서 뽑은 프레임** (시험 문제를 미리 보는 셈이 됨)

## 5. Roboflow 설정 (중요)

| 단계 | 설정 | 이유 |
| --- | --- | --- |
| Split | Train 70% / Valid 20% / Test 10% | 테스트 세트는 최종 성능 보고에만 사용 |
| Preprocessing — Auto-Orient | 켬 | 사진 회전 정보 반영 |
| Preprocessing — Resize | **끄거나 "Fit within 1280×1280"** | 기본값(640 Stretch)으로 내보내면 960·1280 비교 실험이 무의미해짐 |
| Augmentation | 추가하지 않음 | YOLO 학습 단계의 증강만 쓰여야 실험 비교가 깔끔함 |
| Export | YOLOv8 형식 | |

라벨링이 끝나면 Health Check에서 부류별 박스 수를 확인해 보고서의 데이터 표에 적습니다.
